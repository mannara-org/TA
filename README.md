
# Impetus

This is a professor aid tool to handle day-to-day managing of student grades, attendance, homework, etc...

The initial scope of the idea includes:

- It should be fully excel compatible and should export to it. (ready to upload to the progress platform)
- I think all of this can be grouped using dates so a calendar as a primary view seems adequate.
- It should also handle test grades and homework. Assiduity should also be a metric somehow.
- A list of students in each teaching day with attendance status.
- A customizable timetable
